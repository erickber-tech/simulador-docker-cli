# Simulador Docker CLI

Proyecto universitario para simular comandos básicos de Docker mediante una interfaz de consola.

## Comandos implementados

- docker pull
- docker run
- docker ps
- docker stop
- docker rm
- docker logs

## Ejecución

```bash
python docker_sim.py
```

## Pasos realizados

1. Creación de la carpeta del proyecto.
2. Desarrollo del simulador en Python.
3. Implementación de comandos básicos.
4. Creación del repositorio Git.
5. Publicación en GitHub.
